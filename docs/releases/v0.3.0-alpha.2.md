A fix for the app on Windows.

## Fixed
- **Freezes and flashing windows on Windows.** The app looked up the system's light or dark mode by running a small command-line program every time it redrew. On Windows, each run briefly flashed an empty console window and took tens of milliseconds. That froze the UI for seconds when switching pages or changing settings, and slowed down the Mac display window. The app now asks the OS once and follows light/dark changes as they happen. The same fix makes the Mac app lighter too.

## Compatibility
Works with 0.3.0-alpha.1 on the other machine: nothing changed on the network, so updating just the Windows PC is enough.

## Setup
Same as 0.3.0-alpha.1: unzip `legato-…-windows-x64.zip` (or `arm64`) and run **Legato.exe**. On the Mac, move **Legato.app** to Applications and run `xattr -dr com.apple.quarantine /Applications/Legato.app` before opening it.
