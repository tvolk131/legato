The Mac app is now native SwiftUI, and this is the first alpha with a Developer ID signed, notarized Mac app. Windows keeps the same app as before.

**Pairing now needs Add a device open on both devices.** A device accepts pairing requests only while its Add a device window is open. Open it on both, then pick the other device on one of them. A device that isn't ready refuses with a message saying so. Saved pairings are unaffected.

The protocol is unchanged (13), so alpha.30 can still connect. For testing, install alpha.31 on both machines.

- **MacBook (Apple silicon):** `legato-v0.3.0-alpha.31-macos-arm64.tar.gz` → `Legato.app`.
- **RTX 3070 Windows PC:** `legato-v0.3.0-alpha.31-windows-x64.zip` → `Legato.exe`.
- Windows ARM PCs use `legato-v0.3.0-alpha.31-windows-arm64.zip`.

Quit Legato from its menu/tray before replacing it. Moving from the ad-hoc signed alpha.30 to this signed app may need Accessibility, Input Monitoring and Screen Recording granted again. Settings, pairings and the device identity are kept. If permissions look granted but sharing stays stopped, quit Legato and run:

```sh
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
open /Applications/Legato.app
```

## What's new on the Mac

- A SwiftUI window with Devices and Arrangement, a Settings window (Command-comma) and a menu bar item. Legato shows in the Dock only while its window is open.
- **Open at login** starts Legato hidden in the menu bar, and starts it again if it crashes (at most once a minute). If alpha.30 opened at login, the first launch moves that setting over.
- Opening Legato again shows the copy that's already running.

## Fixes

- When control returns to the Windows PC from the Mac, mouse motion from while the Mac was in use no longer counts as a push, which could send the pointer straight back across the edge.
- A reconnecting device no longer leaves two live sessions. A connection that arrives after unpairing is refused.
- Turning sharing off and on quickly no longer starts two sharing loops.

## Please test

- Pair with Add a device open on both, and check that pairing is refused while it's closed on the other device.
- The upgrade from alpha.30: permissions, the login item carried over, hidden launch at login, and force-quitting Legato while it opened at login (it should come back within a minute).
- Arrangement, file sending and drops, clipboard and settings from the Mac app with the PC. Close and reopen the window during pairing.
- Return from Windows to the Mac along the bottom edge, and hold modifier keys while a device reconnects.

Logs remain `legato-app.log` and `legato-app.previous.log` in the state directory. Hosted CI can't check real input, permissions or the login item, so please report what you see.
