The Mac now verifies virtual-display resolution, Retina scaling, and refresh rate, and explicitly selects the requested mode when applying settings leaves a mismatch.

## Display mode recovery
This is a candidate fix for the viewer failing to open with “the display didn't switch to 3840x2160 (it's (1920, 1080))” after resolution changes in Legato. The underlying cause has not been confirmed. If switching still fails, the Mac log now includes the requested mode, current mode, and available choices to distinguish wrong scaling from stale display information.

The display keeps its existing identity. No macOS display preferences are deleted.

## Validation
Local Mac tests cover 1080p and Retina 4K, refresh changes, display arrangement, closing/reopening, and recovery from forced low-DPI modes. A CLI-only test produced the original error, but both old and new code recover with a normal AppKit event loop, so that result does not prove the reported app bug is fixed. The original sequence through Legato's Windows options still needs confirmation.
