Typing on the Mac's display from Windows works while Legato's window is in front.

## Fixed
- **Keys reach the Mac when Legato's window has focus on the PC.** Legato's windows are built on a library (winit) that signs every app up for raw keyboard input. While one of those windows was in front, Windows then stopped showing Legato its own keystrokes, so none were sent to the Mac. That's why picking Legato from the taskbar (or clicking its window) and then typing on the Mac's display did nothing, while clicking another Windows app first worked. Legato now drops that sign-up; it never used it.
- This very likely also explains keyboard input to the MacBook being intermittent when driving it over the screen edge: it failed whenever a Legato window happened to be in front on the PC.

## Updating
Only the PC needs this version: nothing changed on the Mac, and it still connects to 0.3.0-alpha.9 and later.
