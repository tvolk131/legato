Windows now logs a breakdown of H.264 decoding time every five seconds to help explain the roughly 14 ms observed on the RTX 3070.

Each summary identifies the decoder, backend, and resolution, with average and worst times for input preparation/decoder submission, decoder output calls, GPU wait/readback, and copying pixels into CPU memory. It also reports total decoder time and remaining overhead. The startup self-check is excluded, and resizing starts a fresh measurement window.

These are CPU wall times. GPU wait can include unfinished decoding as well as the staging copy; it is not a measurement of transfer time alone. This release adds diagnostics, not a claimed performance improvement.

## Test on Windows
1. Quit Legato on Windows, extract the matching download, replace your existing `Legato.exe`, and reopen it. Settings and pairing live separately from the executable.
2. Open the Mac's display at 4K with **Sharpest** quality. Scroll or move windows continuously for about a minute, then leave the picture still briefly.
3. Send the `H.264 decoding:` line, several `H.264 decode timing` lines from `legato-app.log`, and an F10 screenshot.

The RTX 3070 PC uses the **windows-x64** download. The Mac can stay on alpha.28; no Mac installation or permission reset is needed. Protocol 10 is unchanged.
