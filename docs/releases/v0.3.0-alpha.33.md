This alpha adds key mappings: a key on one machine's keyboard can act as a different key on the other machine. For example, the PC's Right Ctrl can act as the Mac's fn (Globe) key, to start dictation in apps like Wispr Flow.

The protocol is unchanged (13), so alpha.30 to alpha.32 can still connect, but an older Mac ignores the fn key. For testing, install alpha.33 on both machines.

- **MacBook (Apple silicon):** `legato-v0.3.0-alpha.33-macos-arm64.tar.gz` → `Legato.app`.
- **RTX 3070 Windows PC:** `legato-v0.3.0-alpha.33-windows-x64.zip` → `Legato.exe`.
- Windows ARM PCs use `legato-v0.3.0-alpha.33-windows-arm64.zip`.

Quit Legato from its menu/tray before replacing it. Alpha.32 and alpha.33 are signed with the same Developer ID, so Accessibility, Input Monitoring and Screen Recording should be kept; please report if they weren't. Settings, pairings and the device identity are kept.

## Key mappings

- **On Windows:** Settings → Input → **Add a key mapping**. Choose *On Macs*, press the key on this keyboard (for example Right Ctrl), and choose what it acts as (for example *fn (Globe)*). Mappings are listed under Key mappings, each with a button to remove it.
- Keys can act as fn (on Macs), Command, Option, Control or Shift on either side, Caps Lock, Escape, or F13 to F20.
- Mappings apply on top of the *Mac Command key* setting, and replace it for the keys they map.
- **On the Mac:** the Mac app has no screen for this yet. Mappings for a Mac keyboard driving Windows can be added to `legato.toml` in `~/Library/Application Support/io.github.tvolk131.Legato/`, using web `KeyboardEvent.code` key names:

  ```toml
  [[keys.mapping]]
  target = "windows"
  from = "CapsLock"
  to = "ControlLeft"
  ```

## Other changes

- **The Mac can tell left from right modifiers.** Control, Option, Command and Shift sent to the Mac now say which side of the keyboard they came from, so Mac apps that care about Right Control versus Left Control can tell them apart.
- **The Mac keyboard's fn key** is now picked up while the Mac drives Windows. Windows has no fn key, so it does nothing there unless it's mapped.
- **No stuck keys from mappings.** A key released after its mapping changed releases the key it pressed. When two keys act as the same key, that key stays held until both are released.

## Please test

1. On the PC, map Right Ctrl to fn (Globe) on Macs. With the pointer on the Mac, hold Right Ctrl and check that Wispr Flow starts listening, and stops when you let go.
2. Check whether the PC keeps control after Wispr Flow types its transcription. Wispr Flow's typing counts as input on the Mac, so the Mac may take control back, as alpha.32 logs as `taking back control … (Wispr Flow)`. Please report what you see.
3. In the Add a key mapping dialog, record Alt and the Windows key. The Start menu may open when you let go of the Windows key.
