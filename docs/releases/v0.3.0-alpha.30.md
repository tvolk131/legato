The Windows viewer now mirrors standard Mac cursor shapes over the extra display: text, pointing hand, window/divider resizing, crosshair and prohibited. Cursor updates travel independently of video, including while the picture and pointer are stationary. Movement stays local and immediate.

Unknown/custom or unavailable Mac cursor images fall back to an arrow. The current Windows backend uses a four-way move cursor for grab/grabbing and an arrow for unsupported stock icons such as zoom/copy/link. The macOS global-cursor API is deprecated; fallback preserves ordinary input sharing if it becomes unavailable.

Both machines **must install alpha.30**: the protocol is now 13, and older versions are incompatible. Existing saved pairing and settings are retained.

- **MacBook (Apple silicon):** `legato-v0.3.0-alpha.30-macos-arm64.tar.gz` → `Legato.app`.
- **RTX 3070 Windows PC:** `legato-v0.3.0-alpha.30-windows-x64.zip` → `Legato.exe`.
- Windows ARM PCs use `legato-v0.3.0-alpha.30-windows-arm64.zip`.

Quit Legato from its menu/tray before replacing it. Mac releases still use ad-hoc signing: reset and re-grant Accessibility, Input Monitoring and Screen Recording for the replacement app if needed. Permission troubleshooting commands, after quitting Legato:

```sh
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
open /Applications/Legato.app
```

For testing, use the Windows mouse over Mac text, links and window edges/corners in both windowed and full-screen viewers. Repeat with the Mac trackpad, leave/re-enter the picture, and close/reopen it. Confirm ordinary typing, clicking, scrolling and handover remain unchanged. Hosted CI and the Mac cursor probe cannot verify the complete two-machine behavior; please report cursor mismatches or flicker with the app/target involved.

This release also includes the input routing, pointer-edge wrapping, file-transfer/settings robustness, display-arrangement and UI improvements merged since alpha.29. The unverified Windows resize graphics fork was removed; the reported main-window resize wobble remains unresolved.
