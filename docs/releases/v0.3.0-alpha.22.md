The "Show as a display" options are compact enough to see at a glance.

## Changed
- **Each choice is now one row of buttons** (Material 3 Expressive's connected button groups) instead of a list of radio buttons. A line under each row describes the current choice. At the window's default size everything fits without scrolling.
- **Related choices are nested.** Pick full screen or a window first; the display to use only appears for full screen. Likewise, the size while things move only appears under Adaptive quality.
- **Frame rates the Mac can't keep up with** at the chosen size are greyed out, as before.
- With more than four displays, the display is picked from a list.

## Updating
Either machine can take this version on its own: it still connects to 0.3.0-alpha.18 and later.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
