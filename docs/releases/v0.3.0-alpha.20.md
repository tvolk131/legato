Legato's window moves to iced-m3 0.1.0-beta.4 and Material 3 Expressive.

## Changed
- **Expressive motion throughout.** Buttons change shape as you press them. Switches, the slider, dialogs and the navigation rail move with springs instead of fixed timings. Reduced motion is still honored.
- **The navigation rail can expand.** The menu button at the top of the rail shows each page's name beside its icon.
- **"Show as display" is a split button.** Its menu holds the display options (formerly the separate "Options…" button).
- **The Control setting is a connected button group**, Expressive's replacement for segmented buttons. The chosen option is filled.

## Fixed
- **The "Nearby" spinner keeps turning** while Legato's window isn't in front (fixed in iced-m3 beta.3).
- **Tooltips also appear when you move to a control with the keyboard**, not only on hover (iced-m3 beta.4).

## Updating
Either machine can take this version on its own: it still connects to 0.3.0-alpha.18 and later.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
