Control-arrow shortcuts typed from the PC work on the Mac.

## Fixed
- **Ctrl+← and Ctrl+→ switch spaces on the Mac**, and Ctrl+↑ and Ctrl+↓ open Mission Control and the app's windows, when typed on the PC's keyboard with the pointer on the Mac (on the MacBook, or on its extra display). A Mac keyboard marks the arrow keys as function keys, and macOS only recognizes these shortcuts with that mark. Keys typed from the PC now carry the same marks a Mac keyboard puts on them (arrows, F keys, Home, End, Page Up/Down, Forward Delete, and the keypad).

## Updating
Only the Mac needs this version: it still connects to 0.3.0-alpha.18.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
