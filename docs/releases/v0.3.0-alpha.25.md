Less background traffic between the machines.

## Changed
- **Pointer updates to the other machine are paced.** Once the pointer has moved between machines, the one you're using tells the other where its pointer is, so the other's mouse can carry on from there. That used to happen with every move: up to 1000 times a second with a gaming mouse, all day. Now it's at most about 60 times a second, plus once more where the pointer stops. Switching mice still carries on from exactly where the pointer is. The Mac's pointer on its extra display, shown on the PC, still follows every move.

## Updating
Either machine can take this version on its own: it still connects to 0.3.0-alpha.23 and later.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
