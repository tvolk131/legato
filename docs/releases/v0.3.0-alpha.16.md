The Mac's trackpad drives the PC normally.

## Fixed
- **Driving the PC with the Mac's trackpad moves the cursor the way you move your finger.** In 0.3.0-alpha.15 it behaved like a laptop's pointing stick: the further your finger had travelled, the faster the cursor moved, and it stood still only when you came back to where you started. The alpha.15 fix for the bouncing pointer now applies only to the one movement right after the Mac parks its hidden cursor, which is the only one macOS gets wrong.

## Updating
Only the Mac needs this version: it still connects to 0.3.0-alpha.14 and later.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
