Much less lag when showing the Mac as a display on Windows.

## Faster
- **About 65 ms less delay on every frame.** The Mac's video encoder was holding about five frames before handing them over, so the picture on Windows trailed what the Mac drew by about 80 ms at 60 fps, before any network or decoding time. Each frame is now sent as soon as it's encoded, which takes about 16 ms at 4K. This also fixes the last few frames of a movement sometimes arriving late when the screen goes still.

## Fixed
- A display that was just removed and immediately shown again could come up without a size. Legato now waits for macOS to finish removing the old one and checks the new one really took its size.

## Compatibility
Works with 0.3.0-alpha.1 and later on the other machine. **Update the Mac** to get the faster display: the fix is in the encoder, which runs on the Mac.

On the Mac, move **Legato.app** to Applications and run `xattr -dr com.apple.quarantine /Applications/Legato.app` before opening it.
