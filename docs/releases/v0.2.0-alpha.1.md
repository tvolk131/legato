The first build with the **Legato app**, and both machines can now drive each other.

## New in this alpha
- **The Legato app.** It lives in the tray (menu bar on the Mac): pair nearby devices with a 6-digit code, drag screens around in the arrangement editor, and change settings. It can start at login.
- **Either direction.** The Mac's keyboard and trackpad can drive the Windows PC too. Under Settings → Control, choose "Whichever machine you touch" (the default) or "One machine controls" and pick which. The choice is shared between your machines.
- **Clipboard.** Copy on one machine and paste on the other: text, images, and files (up to 512 MB at a time through the clipboard). Turn it off under Settings → Clipboard.
- **Files.** "Send files…" next to a device sends files or folders; they land in `Downloads/Legato` on the other machine. On Windows you can also drag files from Explorer across the edge and let go on the Mac.
- **Arrangement stays in sync.** Place the Mac below your middle monitor on either machine and the other side mirrors it.

## Not yet
- Dragging files out of Finder onto Windows (use copy and paste, or Send files…).
- The Mac shown as an extra display on Windows.

## Setup

**Mac** (`legato-…-macos-arm64.tar.gz`): open it and move **Legato.app** to Applications. The build isn't notarized yet, so the first time, right-click it and choose **Open**, or run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
```
macOS asks for Accessibility access. Allow it in System Settings → Privacy & Security → Accessibility, then open Legato again.

**Windows** (`legato-…-windows-x64.zip`, or `arm64` for Snapdragon PCs): unzip it and run **Legato.exe**. If SmartScreen warns, choose More info → Run anyway. If Windows Firewall asks, allow access. If your network is marked **Public**, also tick "Public networks", or switch the network to Private in Settings → Network & internet.

The command-line `legato` is still included for troubleshooting (`legato doctor`, `legato run -v`); on Windows it's in the `cli` folder. Quit the app before using `legato run`, since only one can share at a time.

## Try it
1. Open Legato on both machines. Pick the other machine under **Nearby** and confirm the code on both.
2. In **Arrangement**, drag the Mac's screen below your middle monitor.
3. Push the cursor down through the bottom of the middle monitor, a little past the taskbar. Push up past the Mac's menu bar to come back.
4. Copy something on one machine and paste it on the other. Drag a file from Explorer down onto the Mac and let go.

## Please report
- The output of `legato doctor` from both machines, and the app's log if something misbehaves.
- In particular:
  - Is the Windows cursor hidden while you're on the Mac?
  - Is the scroll direction right both ways? (Settings → Scrolling has an invert switch.)
  - Do Cmd shortcuts work from the Windows keyboard (Alt+C / Alt+V / Alt+Tab), and Ctrl shortcuts from the Mac keyboard on Windows (Cmd+C / Cmd+V)?
  - Does the Mac show up under Nearby on Windows while the network is marked Public?
