**Virtual monitor mode:** your Mac can now appear as an extra display on your Windows PC.

## New in this alpha
- **Show a Mac as a display.** In the Windows app, click **Show as display** next to your connected Mac. The Mac gets an extra display, and Windows shows it in a window. Press **F11** in that window for full screen on whichever monitor it's on.
- **Use it with the Windows mouse and keyboard.** While the pointer is over the picture, clicks, typing and scrolling go to the Mac. Move off the picture and you're back on Windows. Touching the Mac's own trackpad or keyboard still hands the Mac back.
- **Sharp on 4K.** By default the display is 3840×2160 in Retina mode, so it looks like 1920×1080 and is pixel-sharp full screen on a 4K monitor. To change the size, frame rate or quality, edit `[extend]` in `legato.toml` (in the folder `legato doctor` shows).
- Drag windows onto it from the Mac's own screen like any other display. Arrange it in System Settings → Displays.
- `legato doctor` on the Mac now shows whether Screen Recording is allowed.

## First use on the Mac
Showing the display needs **Screen Recording** permission for Legato on the Mac. The first time, macOS asks. Allow it in System Settings → Privacy & Security → Screen & System Audio Recording, then click **Show as display** again. Because this build isn't signed with a Developer ID yet, macOS may ask again after each update.

## Also in this release
Everything from 0.2.0-alpha.1: either machine drives the other, clipboard sharing (text, images and files), sending files and dragging them across the edge from Windows, and the tray app.

## Setup
**Mac** (`legato-…-macos-arm64.tar.gz`): open it and move **Legato.app** to Applications. The first time, right-click it and choose **Open**, or run `xattr -dr com.apple.quarantine /Applications/Legato.app`. Allow Accessibility when asked, then open Legato again.

**Windows** (`legato-…-windows-x64.zip`, or `arm64` for Snapdragon PCs): unzip it and run **Legato.exe**. If SmartScreen warns, choose More info → Run anyway. Allow access through Windows Firewall. If your network is marked Public, also tick "Public networks", or switch it to Private.

Both machines need this version: it won't connect to 0.2 or earlier.

- Whether stopping (closing the window, or quitting either app) always removes the display from the Mac.
- CPU use on Windows while it's shown in full screen (Task Manager).
