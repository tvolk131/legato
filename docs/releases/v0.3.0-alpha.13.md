The Mac's display keeps playing while Legato's main window is in front.

## Fixed
- **The Mac's picture no longer freezes while Legato's main window is active.** Each new picture used to make the app redraw all of its windows. Windows paints an app's windows one at a time, the window in front first, so the main window's redraws took every turn and the Mac's picture never got one. That lasted until you clicked another app, including after clicking from the main window onto the Mac's picture, since that click goes to the Mac and the main window stays in front. Now each picture repaints only the Mac's display window.
- The main window no longer redraws 60–144 times a second for nothing while the Mac's display is shown.

## Updating
Only the PC needs this version: nothing changed on the Mac, and it still connects to 0.3.0-alpha.9 and later.
