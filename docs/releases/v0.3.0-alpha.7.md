Fixes the Windows app closing when you click **Show as display**.

## Fixed
- **Showing the Mac as a display no longer closes the app.** The display window reports its size as soon as it opens, and Legato started its "wait until resizing settles" timer in a way that crashed the app. Found thanks to the crash log added in alpha.6.
- **Dropping files onto the Legato window no longer closes it,** which failed the same way.

## Compatibility
Works with 0.3.0-alpha.5 and alpha.6 on the other machine. Only the Windows PC needs this update.
