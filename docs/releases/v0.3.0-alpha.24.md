Legato copes better with graphics trouble, such as a PC that has just woken from sleep.

## Fixed
- **A graphics error no longer has to take Legato down.** Opening the Mac's display on a PC that had just woken from sleep crashed Legato: DirectX couldn't resize the new window's drawing buffers ("Not enough memory resources"). Errors like that are now logged, and Legato tries again on the next frame.
- **If Legato does crash, it starts again by itself**, so sharing carries on; reopen the Mac's display if it was showing. It won't restart more than once a minute, so something that keeps failing doesn't loop.

## Changed
- **The previous run's log is kept** as `legato-app.previous.log`, next to `legato-app.log`. After a crash, it's the one that says why.
- **The log names the graphics card and driver** at startup. On Windows it also notes when the PC goes to sleep and wakes up.

## Updating
Either machine can take this version on its own: it still connects to 0.3.0-alpha.23.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
