The Mac's pointer is visible on its extra display when you move it there with the Mac's trackpad.

## New
- **The PC's cursor shows the Mac's pointer on the Mac's display.** Moving onto the extra display with the MacBook's trackpad used to leave the pointer invisible, because the picture never includes the Mac's cursor. Now the PC shows its own cursor at the same spot, the same way it does when you use the PC's mouse. It follows at network speed, not at the picture's delay, so it stays snappy even when the picture lags. Clicks and typing still go to the Mac.

## Fixed
- If the Mac took over the PC just as the PC was handing control back, the PC's cursor could jump back to where it had left the screen. It now stays where the Mac put it.

## Diagnostics
- Moving from the MacBook onto the PC with the Mac's trackpad (no extra display) can leave the PC's cursor invisible until you click. I couldn't reproduce that on test machines. The PC now logs what Windows says about its cursor a moment after the Mac takes over: where it is, and whether it's showing or suppressed. If it happens again, those lines in the PC's `legato-app.log` will show why.

## Updating
**Update both machines:** this version won't connect to earlier ones.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
