Diagnostics for two problems: the Windows app closing when you click **Show as display**, and typing on the Mac from Windows cutting out.

## Changed
- **Crashes are logged.** If Legato closes unexpectedly, `legato-app.log` now says why, including where in the code it happened. The log is in `%APPDATA%\tvolk131\Legato\data` on Windows and `~/Library/Application Support/io.github.tvolk131.Legato` on the Mac.
- **Hand-offs are logged.** When the Mac takes control back because its own keyboard or trackpad was used, both logs say so, and the Mac's says what was used. If typing on the Mac stops working, this shows whether that's the cause.

## If the Windows app closes when you show the display
Please send `legato-app.log` from the PC after it happens. If you can, also try starting Legato from PowerShell in its folder like this, and say whether it still closes:
```powershell
$env:ICED_PRESENT_MODE = "vsync"; .\Legato.exe
```

## Compatibility
Works with 0.3.0-alpha.5 on the other machine. Only the Windows PC needs updating for the crash log; update the Mac too to log hand-offs there.
