Legato's window no longer keeps the CPU busy while it sits on the Devices page.

## Changed
- **Adding a device has its own dialog.** Choose **Add a device…** under your paired devices to see Legato devices on the network that aren't paired yet, and pick one to pair as before. A badge on the button counts any that are waiting. Pairing started from the other device still pops up wherever you are.

## Fixed
- **About a quarter of a CPU core used while idle** (seen on a MacBook with Legato's window open). The "Looking for Legato on this network…" spinner on the Devices page never stopped once all your devices were paired, and every frame of it redrew the whole window, up to 120 times a second. It's now only in the "Add a device" dialog, so it only spins while you're looking.

## Updating
Either machine can take this version on its own: it still connects to 0.3.0-alpha.18 and later.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
