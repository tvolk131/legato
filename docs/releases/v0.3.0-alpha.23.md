Connected machines share one Caps Lock.

## New
- **Caps Lock is the same on both machines, lights included.** Press it on either keyboard, whichever machine has the pointer, and both machines' Caps Lock follow, along with the lights on their keyboards. It stays in sync whenever they're connected, and they agree as soon as they connect.

## Fixed
- **Caps Lock pressed on the PC while it drives the Mac** only affected the letters Legato typed on the Mac: neither machine's real Caps Lock or light changed.

## Updating
**Both machines need this version.** It won't connect to 0.3.0-alpha.22 or earlier.

On the Mac, quit Legato, install the new version, then run:
```sh
xattr -dr com.apple.quarantine /Applications/Legato.app
tccutil reset Accessibility io.github.tvolk131.legato
tccutil reset ListenEvent io.github.tvolk131.legato
tccutil reset ScreenCapture io.github.tvolk131.legato
```
Then open Legato and allow the prompts.
