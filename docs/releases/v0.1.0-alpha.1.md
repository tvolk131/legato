The first build worth trying: **a Windows PC's keyboard and mouse driving a Mac**.

Command line only. There's no UI yet.

## Works in this alpha
- Automatic discovery on the local network, and pairing by confirming a 6-digit code on both machines.
- Paired machines connect directly on the LAN, or through a relay when they're on different networks.
- Moving the cursor from Windows onto the Mac, with resistance at the edge so the taskbar and menu bar don't cause accidental switches.
- Mouse movement, clicks (double and triple too), dragging, the scroll wheel, and the keyboard. Alt and the Windows key are swapped by default, so the key next to the space bar is Command.
- Touching the MacBook's own trackpad or keyboard hands the Mac back to you.

## Not yet
- Clipboard, files, the settings/tray UI, the Mac controlling Windows, and the Mac shown as an extra display on Windows.

## Setup

**Mac** (`legato-…-macos-arm64.tar.gz`)
```sh
tar xzf legato-*-macos-arm64.tar.gz && cd legato-*-macos-arm64
xattr -d com.apple.quarantine legato   # the build isn't notarized yet
./legato pair
```
The first time, macOS asks for Accessibility access for the terminal app you run it from. Allow it, then start `legato` again.

**Windows** (`legato-…-windows-x64.zip`, or `arm64` for Snapdragon PCs): unzip it, open PowerShell in that folder, and run:
```powershell
Unblock-File .\legato.exe
.\legato.exe pair
```
If Windows Firewall asks, allow access. If your network is marked **Public**, also tick "Public networks", or better, switch the network to Private in Settings → Network & internet.

## Try it
1. **Pair.** Run `legato pair` on both machines, pick the other one from the list on either side, and check that both show the same code.
2. **Say where the Mac sits** (on Windows). `legato doctor` lists your displays, numbered left to right. Then:
   ```powershell
   .\legato.exe layout "<your Mac's name>" --side below --display 2
   ```
3. **Run it on both machines:** `legato run`.
4. **Move across.** Push the cursor down through the bottom of the middle monitor, and keep pushing a little past the taskbar. Push up past the Mac's menu bar to come back.

## Please report
- The output of `legato doctor` from both machines.
- If anything misbehaves, the output of `legato run -v`.
- In particular:
  - Is the Windows cursor hidden while you're on the Mac?
  - Is the scroll direction right? (If not, set `invert_wheel = true` under `[scrolling]` in `legato.toml`, in the Mac's "State" folder shown by `legato doctor`.)
  - Do Cmd shortcuts (Alt+C / Alt+V / Alt+Tab) work?
  - Does the pointer speed feel right?
